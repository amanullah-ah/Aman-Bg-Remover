# 🚀 Aman-Bg Remover

A powerful and free AI-based background remover tool that removes image backgrounds instantly with high-quality output.

## ✨ Features
- 🎯 One-click background removal
- ⚡ Fast and smooth processing
- 🖼 High-quality transparent PNG output
- 📱 Mobile-friendly design
- 💯 100% Free to use
- 🚫 No watermark
- 🔥 Simple and modern UI

## 📸 How to Use
1. Upload your image  
2. Remove the background automatically  
3. Download your transparent PNG file  

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  
- AI Background Removal API
